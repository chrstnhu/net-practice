## 🎯 About

**NetPractice** is a **web-based learning tool** to understand how computer networks operate.
It challenges us to configure multiple networks by correctly setting **IP addresses, masks, and gateways** so that all devices can communicate.

---

## ✨ Features

### Core Features

* 🧮 Configure IP addresses and subnet masks
* 🔄 Define routes between different networks
* 🧠 Understand subnetting and gateway logic
* 🧱 Progressive exercises increasing in difficulty
* 🌍 Visual feedback showing connection success or failure

---

## 🎓 Goals

* Understand **IPv4 addressing** and **binary notation**
* Master **subnet masks** and **network segmentation**
* Learn **routing principles** (direct vs indirect routing)

---

## 🧭 Usage

1. Open the NetPractice project from the 42 Intranet
2. Read the exercise instructions carefully
3. Configure each device by clicking on it
4. Set **IP addresses**, **masks**, and **gateways** according to the network plan
5. Validate your configuration — all devices must turn **green**
